# arnook.app

The public marketing and legal site for **Arnook** — a home goods marketplace
where you see it in your space before you buy.

Static, self-contained pages (no build step, no external requests):

- `index.html` — landing page
- `privacy.html` — privacy policy
- `support.html` — support & FAQ

Served via GitHub Pages at https://arnook.app. `CNAME` binds the custom domain;
see `DNS-SETUP.md` for the registrar records.
